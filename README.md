
# 💰 Expense Tracker App

A simple and responsive Expense Tracker built using HTML, CSS, and JavaScript. It helps users manage their income and expenses and calculate their remaining balance.

## ✨ Features

- Add income transactions.
- Add expense transactions.
- Automatically calculate total income, expenses, and balance.
- Delete individual transactions.
- Save transactions using browser localStorage.
- Responsive design for mobile and desktop.
- Simple and user-friendly interface.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser localStorage

## 🚀 How to Run

1. Download or clone this repository.
2. Open `index.html` in your web browser.
3. Enter a transaction description and amount.
4. Select Income or Expense.
5. Click **Add Transaction**.
6. View your balance and transaction history.
7. Click Delete to remove a transaction.

## 💾 Data Storage

Transactions are stored locally in your browser using localStorage. Data is not uploaded to a server or automatically shared with other devices.

Clearing browser site data or using a different browser may remove or hide your saved transactions.
